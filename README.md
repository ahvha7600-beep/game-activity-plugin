# game-activity-plugin

# Local Game Activity Plugin (локальный блок активности игры)

Этот плагин добавляет локальный блок игровой активности в профиль под музыкальным блоком. Блок отображает:
- иконку игры (берётся из папки `icons/`)
- название игры
- текст "Playing"
- таймер (показывает время с момента выбора игры, обновляется каждую секунду)

Важно: блок локальный — он отображается только на вашем клиенте и не меняет серверный профиль Telegram.

---

Структура репозитория:
```
plugin/               # код плагина
  ├─ game_activity.py
  ├─ __init__.py
  └─ manifest.json
icons/                # положите сюда иконки игр (png/jpg/webp/svg)
README.md
```

Установка
1. На ПК (Windows/Linux/macOS)
   - Скопируйте папку `plugin/` и `icons/` в каталог плагинов вашего клиента (см. документацию Exteragram/AyuGram).
   - Если клиент требует .plugin архив — упакуйте содержимое в zip и переименуйте в `yourname.plugin`:
     - zip: `zip -r local-game-activity.plugin plugin icons README.md`
   - Перезапустите клиент и включите/установите плагин через интерфейс клиента.

2. На телефоне (Android)
   - Аналогично: загрузите `plugin/` и `icons/` в каталог плагинов мода (внутреннее хранилище или папку плагинов).
   - Если мод-клиент позволяет импорт .plugin — используйте импорт.
   - Убедитесь, что у приложения есть доступ к файловой системе (чтобы читать `icons/` и JSON).

Как добавить иконки и игры
- Поместите иконки в папку `icons/`.
- Рекомендуемый формат имени файла: точное имя игры (включая пробелы), например:
  - `icons/AmongUs.png`
  - `icons/Call of Duty.png`
- Поддерживаемые форматы: png, jpg, jpeg, webp, svg.
- При вызове `set_game("AmongUs")` модуль попытается найти `icons/AmongUs.png`. Он также проверит варианты с нижним регистром и подчёркиваниями.

API плагина (основные функции)
- set_game(name) — выбрать игру и запустить таймер. Пример:
  ```python
  from plugin import GameActivityManager, ConsoleAdapter
  mgr = GameActivityManager(ConsoleAdapter())
  mgr.set_game("AmongUs")
  ```

- stop_game() — остановить таймер и скрыть блок.
  ```python
  mgr.stop_game()
  ```

- change_game(name) — сменить игру и перезапустить таймер (эквивалент set_game):
  ```python
  mgr.change_game("CSGO")
  ```

Сохранение состояния
- Выбранная игра и время старта сохраняются в `plugin/game_activity_state.json`.
- При перезапуске плагина, если состояние показывает активную игру, таймер продолжит работать (локально) с сохранённого времени.

Интеграция с Exteragram/AyuGram (шаблон)
- В `plugin/game_activity.py` есть класс `TelegramClientAdapter` — это шаблон адаптера.
- Подставьте в него реальные вызовы API вашего клиента:
  - Создание локального блока профиля (show_block)
  - Обновление блока (update_block)
  - Удаление блока (hide_block)
- Пример псевдо-интеграции в `show_block`:
  ```python
  self.client.set_local_profile_card({
    "id": "game_activity",
    "icon": icon_path,
    "title": title,
    "text": status_text,
    "right_text": timer_text
  })
  ```
  Точный метод и структура зависят от API мод-клиента. Посмотрите документацию Exteragram/AyuGram или их примеры плагинов — используйте соответствующие вызовы.

Советы по отладке
- Используйте `ConsoleAdapter()` для локальной отладки в Python (вывод в консоль).
- Проверьте корректность путей: `icons_dir` вычисляется относительно корня репозитория (один уровень выше `plugin/`).
- Если блок не отображается на телефоне, убедитесь, что клиент поддерживает локальные UI-блоки и что вы правильно реализовали адаптер.

Частые вопросы
- Можно ли сделать так, чтобы блок синхронизировался на сервере?  
  Нет — этот плагин специально локальный, он не меняет серверный профиль.

- Что делать, если иконка не загружается?  
  Проверьте имя файла и поддерживаемое расширение. Логика поиска ищет точное совпадение "Name.ext" и также пробует вариант с нижним регистром и подчёркиваниями.

- Как запустить таймер вручную?  
  Вызовите `set_game(name)` в коде/консоли/скрипте. Таймер запускается при выборе игры.

Примеры использования
- Быстрый тест в консоли:
  ```python
  from plugin import GameActivityManager, ConsoleAdapter
  mgr = GameActivityManager(ConsoleAdapter())
  mgr.set_game("AmongUs")
  # через 10 сек
  # mgr.change_game("CSGO")
  # остановка
  # mgr.stop_game()
  ```

Готовность под телефон и ПК
- Плагин написан на чистом Python и не использует зависимости, специфичные для ОС.
- Реальная работа UI зависит от адаптера — нужно реализовать методы `show_block/update_block/hide_block` через API клиента. В README описано, где внести изменения.

Если нужна — могу:
- Подготовить конкретный адаптер для вашего клиента (Exteragram или AyuGram), если вы пришлёте ссылку на документацию API плагинов этого клиента или пример существующего плагина.
- Сгенерировать пример иконок (заглушки) в формате PNG для теста.
