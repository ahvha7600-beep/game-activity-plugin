# Game Activity Plugin (локальный блок активности)

Этот плагин добавляет локальный блок игровой активности: иконка игры, название, текст "Playing" и таймер, который показывает время с момента выбора игры.

Файлы:
- game_activity.plugin — основной плагин (Python)
- icons/ — папка для иконок
- README.md — этот файл

Как использовать (быстрый старт)
1. Скопируйте `game_activity.plugin` и папку `icons/` в папку плагинов вашего клиента (Exteragram/AyuGram) или в корень репозитория.
2. Поместите иконки в `icons/`. Рекомендуемый размер 64x64 или 128x128 PNG.
   - Имена файлов: `AmongUs.png`, `CSGO.png`, `Call of Duty.png` и т.п.
3. Перезапустите клиент/подключите плагин.
4. В чате используйте команды:
   - `.setgame <name>` — выбрать игру и запустить таймер
   - `.changegame <name>` — сменить игру (перезапустить таймер)
   - `.stopgame` — остановить таймер и скрыть блок

API плагина (методы)
- set_game(name) — выбрать игру и начать отсчёт
- change_game(name) — сменить игру (сброс таймера)
- stop_game() — остановить и скрыть блок

Где хранится состояние
- Состояние хранится в JSON-файле `game_activity_state.json` рядом с файлом плагина.
- При перезапуске плагина состояние читается — если игра была активна, блок и таймер продолжают отображаться.

Адаптация под клиента
- Плагин пытается вызвать распространённые API-методы:
  - `set_local_profile_card(payload)` / `create_local_profile_card(payload)`
  - `update_local_profile_card(id, fields)`
  - `remove_local_profile_card(id)`
- Если в вашем клиенте названия методов другие — замените вызовы в функциях:
  - `_client_show_block`, `_client_update_block`, `_client_hide_block`

Отладка
- Если блок не отображается, проверьте логи клиента (android_utils.log).
- Убедитесь, что `icons/` доступна плагину и что имена файлов совпадают с именами игр.
- В некоторых клиентах нужно использовать другой API для создания локальных блоков — пришлите пример API/документацию, и я адаптирую код.

Примеры
- В чате:
  - `.setgame AmongUs`
  - `.changegame CSGO`
  - `.stopgame`
